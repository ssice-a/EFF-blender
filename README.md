# EFF Blender 插件

EFF Blender 用于把 AnimeStudio 导出的资源制作成游戏 Mod。你可以在 Blender 中编辑网格、材质、贴图、款式切换、形态键和粒子特效，然后导出可放入 EFF `plugin/mods` 的 Mod 文件夹。

本次发布 **v0.48.0**，配套 [EFF v1.9.0](https://github.com/ssice-a/EFF/releases/tag/v1.9.0) 与 [AnimeStudio v1.8.1](https://github.com/ssice-a/AnimeStudio/releases/tag/v1.8.1)。Windows x64 插件包含原生导出核心、统一资源编译器、索引刷新工具及 Pillow；已在 Blender 5.0.1 / Python 3.11 验证。当前包支持 Windows x64 / Blender 5.0，内置依赖使用 Python 3.11 ABI；不同 Python ABI 需要另行构建依赖。

带截图的[简易 Mod 制作教程](https://github.com/ssice-a/EFF/blob/main/Mod%20Tutorial.md)包含安装、解包、材质编辑和所选网格导出步骤；也提供[英文版](https://github.com/ssice-a/EFF/blob/main/Mod%20Tutorial_EN.md)。

游戏更新后，先用 AnimeStudio 更新原解包来源，再从原 Blender 工程重新导出即可，无需重新导入角色或使用 Mod 修复工具。

## 功能

- 导入和编辑 EFF 网格、材质、贴图、骨骼、LOD 与物理资源。
- 支持多个部件、材质槽和形态键。
- 为形态键提供 Blender 滑块，并可按需录制游戏快捷键。
- 在 N → EFF → 形态动画组管理中统一管理多网格播放组；每成员独立 Action/KEY slot，同一网格可加入多个组。游戏快捷键控制播放，Ins 提供暂停与实时倍率。
- 创建款式切换组，设置默认款式和游戏快捷键。
- 创建款式切换组时即可录制游戏快捷键；后续仍可在组设置中改键。
- 将 `.efffx` 导入为空物体特效层级，按模块编辑发射器、生命周期、曲线、渐变、Billboard 序列帧、Mesh、材质和贴图；支持增删发射器及多个特效统一导出。
- 在 Blender 场景中预览常用粒子、形状、Mesh 和序列帧；可将特效挂到角色骨骼，或导出独立特效 Mod，并覆盖全部 LOD。
- 导出 format 2 完整 Mod，或更新已有 Mod 的 Mesh、材质和贴图；导出按键切换选项默认开启。
- 分资源导出复用当前会话 Mesh 快照；同一次导出复用共享骨架的路径、供体及绑定信息；仅贴图导出保留已有完整 Mod 的其他资源。
- 自动生成每个 Mod 的 `source-inputs.bin`，只编译当前导出的独立 Mod，生成 `compiled.bin`。
- 同一游戏材质可作为多个独立作者材质的模板，各自保留参数和贴图绑定。
- 在 EFF 面板中检查 main 的已测试完整更新包，按提交号识别 Python 更新，下载校验后退出 Blender 自动安装并保留备份；也可只检查正式 Release。

## 安装

从 [Releases](https://github.com/ssice-a/EFF-blender/releases) 下载 `EFF_Blender_v0.48.0.zip`，在 Blender 的插件设置中选择“从磁盘安装”，然后启用插件。旧版需要手动升级这一次以取得更新器。更新前保存工程、关闭 Blender，再替换旧插件并重新启动，以释放原生 DLL 和旧 Python 模块。

之后可在 **N → EFF → EFF 更新**选择“仓库更新（自动测试）”，点击“检查更新”和“下载并准备更新”。下载期间可继续编辑；出现准备完成提示后，自行保存工程并关闭全部 Blender，更新器再替换插件，下次启动生效。不会自动保存、关闭工程或修改 Mod。旧插件位于插件父目录 `.eff-update-backups` 下，可在 Blender 关闭时恢复。

仓库更新只发布通过自动测试的完整包，包含固定摘要核验的原生工具和 Python 依赖，不使用缺少 nativepack/vendor 的 GitHub 源码 ZIP。main 推送后自动生成更新包并维护一个持续更新下载页，无需每次手工发版或改版本号；以安装包记录的提交 SHA 比较更新。正式 Release 仍可独立发布和选择。源码链接／Git 开发安装继续使用 Git，不自动替换代码目录。

原生基础包由 `native-base.json` 固定下载地址、大小、SHA256 和配套框架版本。仅改 Python／UI 时复用这些工具；修改原生编译器、作者核心、解析器或依赖时，维护者必须先构建并验证新的完整基础包，再更新该记录。打包会再次核对当前 Python 所要求的编译器协议。

## 制作 Mod

### 导入表情动画

在 AnimeStudio 中勾选表情动画资源及一个角色的 SkeletalMorph Avatar，使用 **Export → Format specific → EFF → Checked facial animations as EFF library...** 导出 `.eanim`。此步骤不需要 PostModel，也不扫描整个游戏的模型。

Blender 中选中已经导入的 EFF 骨架或绑定该骨架的网格，选择 **文件 → 导入 → EFF 动画（选中骨架）**。可按类型或名称筛选；默认保留骨架正在使用的 Action。导入的 Action 名称以 `EFF_` 开头，在动作编辑器中选择。重复导入相同内容会复用已导入的动作，不覆盖作者修改；需要的来源辅助骨骼会补入，工程不会自动保存。

目前还原 SkeletalMorph 的骨骼情绪姿态、口型和动态片段。静态姿态只有一帧；动态曲线按来源时间采样。Shader 表情参数、随机眨眼调度及游戏动画资源替换导出不在此入口中。动画文件无需放入游戏 Mod。

位置、导出步骤和格式说明见 [表情动画说明](docs/facial-animation.md)。

1. 在 AnimeStudio 中导出 EFF 源包。
2. 在 Blender 选择 **文件 → 导入 → EFF Mod 包**，打开源包中的 `mod.ini`。
3. 编辑模型、材质和贴图。需要款式切换时，在 **3D 视图 → N → EFF → 网格切换**中创建切换组并设置默认状态。

   **材质属性 → EFF 材质**按功能分组，提供开关、数字和 RGBA 控件；可搜索参数，通过“添加空贴图槽”绑定来源材质已有的空槽。关闭发光、描边会收起详细参数，已有贴图保留显示。设置示例见[材质说明](docs/material-effects.md)。
4. 需要形态键时，在网格数据属性的 **EFF 形态键控制**中点击“接管当前形态键”。这会把已有的 Blender 形态键登记为导出滑块；它不会修改顶点，也不会自动创建游戏快捷键。快捷键需要在同一面板中单独录制。
5. 选择要导出的 EFF 网格和/或特效，在 **文件 → 导出 → EFF Mod 包**统一导出。仅选特效根或子发射器时只导出所属完整特效，可一次多选多个特效；人物与特效一起选中则一起导出，挂载于所选人物 Mesh 的启用特效也会带上。首次选择“全部资源”；后续可用“仅 Mesh”“仅材质与贴图”或“仅贴图”更新已有完整人物 Mod。完整导出窗口中的“导出按键切换”默认勾选；取消后只导出默认款式，不导出款式和形态键快捷键，但仍保留形态键及其滑块。
6. 在 EFF 导出区域填写 Mod 文件夹名，然后在文件浏览器中选择父目录；插件创建或刷新同名文件夹，把 `mod.ini`、`meshes/`、`materials/` 和 `textures/` 写入其中，再在暂存目录中完成独立编译和校验后发布。需要直接在游戏中使用时，父目录选择游戏的 `plugin/mods/`。文件浏览器里的文件名不决定 Mod 名称。
7. 等待导出和离线准备完成，进入游戏后按 **F10** 热重载。按 **Ins** 独立勾选哪些 Mod 接收按键，默认全部启用，允许多个 Mod 同时响应。也可在各 `mod.ini` 的 `[Mod]` 中设置 `key_switch_enabled=0` 或 `1`。实际全局快捷键以游戏 `plugin/eff.ini` 为准。

重复编辑后，用 **文件 → 导出 → EFF 快速更新所选 Mod** 更新上次目录，选择范围仍由本次所选资源决定。纯特效包使用专用目录，游戏按 F9 更新特效；人物包与纯特效包互相覆盖会被拒绝。

导出窗口提供独立的“游戏目录”，可点文件夹按钮选择，也可自动识别；设置记在插件偏好中，供其他工程使用。支持选择游戏根目录、`Endfield.exe` 或启动器的 `games` 目录。多份安装需要明确选择一份。Mod 可以导出到桌面、制作目录或游戏 `plugin/mods`，不要求配置环境变量；游戏目录用于读取当前资源，仍需本机安装游戏。旧的 `EFF_RELOAD_GAME` 配置继续兼容。

### 形态键动画

本次发布已接入此功能，请同时更新配套编译器和 DLL。

1. 选中带 EFF 来源的网格，在形态键的 **value** 上插入关键帧。动作属于 Shape Keys 数据块；网格 Object 的位置、旋转 Action 不能用于此处。
2. 打开 **3D 视图 → N → EFF → 形态动画**，点击“从当前动画创建播放组”。它读取当前 Shape Keys Action、KEY slot 与范围；手动换 Action 后选择对应插槽并“读取动作频道”。
3. 勾选参与播放的频道，设置范围、循环和初始自动播放，再录制游戏快捷键。“更多设置”可调整作者默认倍率和采样率。预览停止后会恢复原 Action、帧和权重。
4. 使用“全部资源”或“仅 Mesh”导出；仅材质/贴图更新会保留已有动画。游戏中快捷键播放/停止；**Ins → 形态动画**支持播放、暂停、停止和实时调速，倍率可直接输入并会保存，调速保持当前进度。

停止恢复手动权重；手动形态滑块或原形态快捷键会先停止关联播放组。第一版每个频道只能属于一个启用的播放组，NLA 和驱动器需先烘焙。F10 后初始自动播放的组从头播放，其余回到停止。该功能已有 Blender、原生控制和隔离编译回归，游戏内动画显示与实际性能仍待验收。详细边界见 [形态动画说明](docs/shape-animation.md)。

导出需要游戏安装路径，请设置 `EFF_RELOAD_GAME` 环境变量指向当前游戏目录；如果输出目录本身位于 `plugin/mods/<Mod>` 下，插件会从目录结构推断游戏目录。插件不保存开发者本机的游戏路径，也不会把固定的 Mod 名称写入代码。

插件只调用自身安装目录中的作者工具，不从游戏或开发目录借用程序。正常来源查询与资源编译仍在 `eff_resource_pack.exe` 内完成。游戏资源更新使工作区索引过期时，自动调用配套的 `eff_source_index.exe`：按 Bundle 内容复用未变记录，只解析变化/新增包并移除退休记录，然后继续本次导出。当前游戏未变时不启动刷新工具；无需打开 AnimeStudio、重新解包或重新导入工程。工具自带运行环境，不需要另装 .NET，完整索引保留在原工作区，不放进插件或 Mod。

Mod 包含独立作者资源、来源描述和压缩 `compiled.bin`；不复制完整游戏原包。输出大小随作者资源、依赖和共享修改变化。真正的来源结构不兼容、更新尚未下载完整或索引刷新失败仍会保留上一 Mod，并报告具体原因。旧 compiled.bin 请使用配套工具重新导出。

导出只处理当前选择的资源。请保留 AnimeStudio 源包和 `.blend` 工程，避免覆盖源资源。

多个作者包可以在 Blender 中共存，同名材质和贴图保持精确来源归属。每个导出 Mod 的 INI 是作者规则入口；F10 统一加载整个 mods 目录，包括多角色的增删与资源修改。全 LOD 导出会把当前作者几何映射到各目标 LOD，不会自动减面。

材质已有的浮点、整数、颜色和四分量参数可在“材质属性 → EFF 材质 → 材质参数”中编辑。材质自定义属性 `eiem_render_queue` 可指定实际渲染队列，在 EFF 面板中显示为“渲染队列”；导出直接写入原生材质的 `m_CustomRenderQueue`，取值为 -1（使用 Shader 默认队列）或 0 至 5000。它与 Shader 辅助属性 `_QueueOffset` 不同。数值修改使用“仅材质与贴图”或“全部资源”导出；新增材质变体或重新分配 Mesh 的材质需要完整导出。共用一个材质的部件共用队列，固定内外层的独立顺序需要不同材质变体。

Shader 功能开关也属于材质数据。可添加自定义属性 `eiem_keyword.<实际关键字>`，用 `1` / `0` 启用或禁用；导出写入原生 keyword 字段。例如游戏 CharacterNPR 的发光需要 `_UseEmission=1` 和 `eiem_keyword._EMISSION=1`，并设置发光贴图、颜色和亮度。仅把图片放入 `_EmissionMap` 不会自动启用发光。透明混合还需要匹配的关键字、混合状态和渲染队列；不能只修改贴图的 Alpha。渲染标签可通过 `eiem_tag.<标签名>` 编辑，例如 `eiem_tag.RenderType`。

导出完成提示的贴图数按实际写入的不同 `.tex` 文件计数。多个材质绑定可共用一个贴图文件；未修改的游戏贴图保持游戏资源引用。

透明裁剪、混合透明、自发光及呼吸/流光的字段和操作步骤见[材质效果设置](docs/material-effects.md)。呼吸和流光的参数存在性已核对，动态效果仍需在游戏验证。

特效导入为根空物体，在 **数据属性 → EFF 特效 · 发射器**编辑模块/曲线/引用；支持基础 Mesh/billboard 离线预览、骨骼挂载。导出统一使用 **EFF Mod 包**，支持多个特效单独打包或随人物导出。普通 eff.dll 使用可配置 F9 重载，无需 PID 或额外 DLL，见[特效编辑说明](docs/effects-editor.md)。

保留源包的 `source/manifest.json` 和 `source/serialized/` 供精确来源和字段模板读取；普通 Blender 导出不读取 `source/streams/` 的原始载荷快照。新解包贴图使用短名称，旧包的哈希名称按自己的 INI/manifest 继续使用，不能只改文件名而不更新引用。游戏 Mod 无需携带原包快照或全局索引。

Physics 参数和预览仍可在作者工具中编辑，新增骨链、球/胶囊碰撞体已接入离线编译，游戏内模拟及物理退出/F10 尚未实机验收。当前测试不代表所有角色或二三十个 Mod 的性能已经验证。

物理编辑集中在 **3D 视图 → EFF → 物理**，按结构、动力、碰撞和高级组织参数；旧对象属性物理面板已移除。列表可搜索物理组/碰撞体，勾选多个组作为参数批量目标。九类曲线在对应参数旁展开，支持复制参数、保存当前工程预设，以及导入/导出跨工程 JSON 预设。内置的 Chen 软飘带预设随插件提供。预设只含动力与高级参数及曲线，不含碰撞参数、碰撞引用、骨骼或链拓扑；应用前会校验模拟类型，目标链保留自己的碰撞设置和碰撞体集合。碰撞集合在目标链的“碰撞”页面单独配置。

选中新建物理组后点击“删除物理链”，会删除该组和它生成的预览、曲线控件，可撤销；骨骼与共享碰撞体保留。游戏源物理组使用“禁用游戏组件”，避免仅从 Blender 删除后游戏仍加载原组件。参数复制不复制骨骼拓扑、Transform 引用、动画或游戏运行时权重；新链的分段、长度、根部绑定和动画不同，运动效果仍可能不同。新增链当前使用 BoneCloth，其他模拟类型不会被静默转换为同一种物理。

碰撞体的固定显示、隐藏及穿透显示只影响 Blender 预览。源碰撞体中心使用 Blender 局部坐标，胶囊使用总长和两端半径。未确认的源结构写回仍保留来源数据；“导出物理作者数据”用于独立作者交换资源。要编译新增骨链，请同时选择受其蒙皮的 Mesh 与骨架，再使用“全部资源”导出；也可显式选择物理组。只选 Mesh 不会自动包含隐藏物理组。新增节点须绑定已确认的来源骨架；球/胶囊碰撞体会生成附属 Transform，平面和既有物理结构的修改暂不属于本轮编译范围。
