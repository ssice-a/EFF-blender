# 特效空物体编辑与预览

2026-10-19 重做版，替代旧侧栏/PID/实例选择流程。当前为本地开发构建，游戏画面尚待实机验收。

## 编辑

特效根的 **挂载与显隐 → 覆盖全部 LOD** 默认开启。角色包沿用挂载 Part 所属 Replace 规则的全部 LOD 目标；同一骨架只有一个特效实例，LOD 切换或补登记网格不重新开始发射。导出同时解除来源 EffectSetting 的距离/画质降级，防止远距离档位关闭发射器。关闭此项会保留来源特效的降级设置。数量、生命周期、速度、网格、材质和贴图参数不随此开关改变。

使用配套的新 AnimeStudio 编译器。旧特效包需要只选特效重新导出，再在游戏按 F9；只有 DLL 更新则需要下次启动游戏才加载。覆盖范围依赖已声明、已验证的模型 LOD 目标，不能只靠同名网格猜测其他模型。纯独立包没有角色 Replace 映射时，仍使用其导出的精确 Renderer 来源证明，不会凭名称扩展到未声明的低 LOD。

1. 配套 AnimeStudio 的 EFF 菜单勾选特效 Prefab，使用 Checked Prefabs as EFF effect sources 导出 .efffx。effect.json 是编辑入口，preview 资产包含真实 Mesh/UV/PNG。
2. Blender 文件 → 导入 → EFF 特效来源，选择 effect.json，得到根空物体、发射器子空物体，以及直接可编辑的来源 Mesh 和绑定材质。网格位于 **特效资源 · 特效名称** 集合，默认隐藏，避免与发射中的预览粒子重叠；在特效结构中点击网格会显示并选中。贴图沿用现有材质页的来源引用与替换方式，不批量载入为作者图片。
3. 选特效空物体，在**数据属性（空物体坐标轴图标）→ EFF 特效 · 发射器**编辑。顶部显示当前编辑的对象类型；展开 **特效结构 · 点击切换编辑对象** 可以直接选择特效根、真实子发射器和材质。基础、发射数量、发射形状默认展开；根显示全部发射器，选子 Empty 只编辑该发射器。运动、外观变化、交互模块按功能组织，展开模块后直接改参数。渲染器单独成块。
4. 参数使用中文功能名；常量/随机范围/曲线/渐变使用模式下拉框，仅展开当前模式所需字段。寿命用秒、出生旋转用 **°**、旋转模块的角速度用 **°/s**；编辑器转换后写回原生弧度，不改动旧工程的旋转值。形状角度本身已经是度，不二次转换；曲线图纵轴显示乘倍率后的结果，旋转也显示角度，高级原生关键点表中的数值仍是倍率。颜色为颜色控件，渐变位置 0..1，Alpha 负责透明度。原生字段路径与类型在悬停说明，高级区保留其余字段，未命名字段为 unknown。float/double 为浮点、32 位整数为整数、bool 为勾选。Blender 不支持完整无符号/64 位整数，这类字段用精确十进制文本并校验原生范围，不经过 float。
5. 所有来源已有的粒子模块标题始终保留。标题左侧的三角负责展开，勾选框负责启停；取消勾选后显示 **未启用**，参数变灰，但标题、开关和全部设置都保留，在原位置重新勾选即可恢复。发射器上方的 **启用模块…** 也可选择未启用模块。它操作当前 ParticleSystem 的既有 schema 槽，每种模块只有一个。定时爆发明确显示时间、数量、重复次数、间隔和概率。数值曲线统一点顶部 **编辑全部曲线**：每个发射器共用一个 Blender Graph Editor，速度、大小、旋转等跨模块分组显示，左侧 Shift 多选一起编辑；右侧 **EFF 曲线** 可搜索添加属性、移出列表或改为常量。添加常量/随机范围会按原数值转换为平直曲线并启用所属模块，编辑自动同步。X/Y/Z 是参数的轴向分量，A/B 是随机双曲线的两端。原生数值表收在 **精确数值 / 原生关键点与切线**。爆发条目同步数量，曲线按时间排序。新增/删除完整发射器使用下文的专用按钮。
6. 来源资源选择器可切换已存在依赖。来源 Mesh 导入即展开并自动绑定；可直接编辑，也可在渲染块另外指定 Blender Mesh。材质编辑页逐槽替换图片。构建时新增独立原生资源，不覆盖来源网格/贴图；未修改的导入网格保持来源引用。

数据随 .blend 保存。根 TRS 是挂载偏移；子发射器 TRS 与原生 Transform 字段双向同步。

在特效根的 **挂载与显隐 → 特效显隐按键** 点“录制按键”，按下一个键或组合键；可以录制多个键，任一键都会切换同一个特效状态。重复键不能添加，点行尾 `X` 删除。运行时按键只控制特效启停，挂载 Mesh 隐藏/禁用时特效仍隐藏；Mesh 恢复显示后，特效按自己的开关状态决定是否出现。没有录制按键时保持默认随挂载 Mesh 显示。

## 先认清结构，再改花瓣

根、发射器和组件关系来自来源 Prefab；“运动”“外观变化”等标题是编辑器按用途分组。Blender 中的材质 Empty 用于保存资源编辑，不会发射粒子。

```text
特效根                         挂载到裙尾骨骼、偏移、构建与导出
├─ 发射器 leaves_01             一组持续发射的粒子
│  ├─ 粒子模块                 形状、数量、出生寿命、速度、旋转、渐隐等
│  └─ 渲染设置
│     ├─ Mesh 引用             每片花瓣的网格与 UV
│     └─ 材质引用 → 贴图槽     花瓣外观、遮罩、透明度等
└─ 发射器 leaves_02             另一组粒子，有自己的模块和渲染设置
```

粉花瓣来源有 `leaves_01`、`leaves_02` 两个发射器，导入后共用可编辑的 `Plane001` 和材质 `M_fxmap_common_camphor_leaves_04`。改一个发射器的数量只影响它；改共用网格或材质会影响两个发射器。Unity 原生绑定仍由渲染器分别引用 Mesh 与材质，编辑器会把网格上实际用于面的 EFF 材质槽导出到对应渲染器。

在顶部 **特效结构** 选一个发射器，逐项调整；**怎么改：花瓣常用参数** 中也有以下位置速查：

| 要改什么 | 在哪里改 |
| --- | --- |
| 裙尾出生区域 | **发射形状与范围** → 类型、形状位置/旋转/尺寸；调整发射器 Empty 位置移动整个发射器 |
| 花瓣数量 | **发射数量** → 每秒发射数；**发射器基础** → 最大同时存活数是上限 |
| 每片存在多久 | **发射器基础** → 出生寿命 (s)；系统周期决定发射器循环时长 |
| 出生时随机角度 | **发射器基础** → 出生旋转 → 随机范围；输入最小/最大角度，单位 °；三轴勾选“分别设置 XYZ 旋转” |
| 飘落中继续旋转 | **旋转随生命周期** → 角速度，单位 °/s；三轴勾选“分别控制 XYZ” |
| 渐隐 | 勾选 **颜色与淡入淡出** → 渐变 → 透明度点；0..1 表示已过寿命比例，末端 Alpha 设为 0；游戏材质需使用粒子 Alpha |
| 每片花瓣的形状 | **渲染：面片 / Mesh / 材质** → 自定义粒子 Mesh |
| 图片和材质参数 | 渲染块 → **编辑材质 / 贴图**；材质页通过 **返回特效根** 或结构导航回发射器 |

例如单个发射器每秒 10 片、寿命 3 秒，稳定时约有 30 片；两个发射器一起开启时需计算总数。预览用根物体的“离线预览 / 显示发射范围”，修改后随时间线检查；部分复杂模块仅支持原生编辑，预览范围见下文。

## 发射器增删与持续生成（2026-10-20）

选特效根或任一发射器，在数据属性顶部点击 **添加发射器…**，选已有发射器模板并输入名称。新增 Empty 有独立的原生 GameObject、Transform、ParticleSystem、Renderer 和配套脚本组件，复制模板当前参数；移动新 Empty 或改模块不会改模板。Mesh 和材质初始共用，需要不同外观时在新发射器的渲染块更换网格/材质。暂不支持无来源模板创建任意组件类型。

选中子发射器，点击顶部 **删除发射器**；可用 Ctrl+Z 撤销。删除后发射器、对应预览和有效游戏层级一起移除，共用资源保留；删光后仍可在“添加发射器…”选择“来源模板”重建。先处理它的子节点/子发射器；特效根负责挂载与导出，不能在这里删除。原生构建同步 EffectSetting 的 LOD 登记，并保留已停用、已脱离层级的来源记录以维持未知引用及 Bundle 预载表，新增发射器有新的原生身份。不要用普通 Shift+D 复制发射器 Empty，导出会拒绝重复来源身份；普通 X 删除也不等于声明原生删除。

**持续生成需要同时检查以下字段：**

1. **发射器基础 → 循环播放**：决定系统周期结束后是否继续发射；**出生寿命**是每片粒子的寿命，二者独立。
2. **发射数量 → 每秒发射数**：右侧模式选“常量”后直接填每秒数量；“曲线”会在系统周期内改变发射速率。
3. **发射数量 → 定时爆发**：每条右侧 X 删除该爆发；清空列表只保留连续发射。每秒发射与爆发会叠加，单独改每秒数量不会清除爆发。
4. **每单位移动发射数**：仅需按时间发射时设为零；它根据挂点移动距离生成。
5. **发射器基础 → 最大同时存活数**：控制容量，容量满时游戏可能停止新生，等旧粒子死亡后再补充。

也可点 **发射数量 → 设为持续发射…**，明确填写每秒数量和存活上限，确认后开启循环、改为常量速率、清除定时爆发和按距离发射；形状、寿命、旋转与外观保留。对每个要改的发射器分别操作，不自动修改用户当前设置。

粉花瓣的来源 `leaves_01` / `leaves_02` 已开启循环，同时存在每轮时间 0 的爆发和非匀速的连续发射曲线，因此会看起来成批出现。来源还带 `VFXAutoEmissiveRate` 脚本，离线预览不执行游戏脚本，最终游戏速率仍需实机确认。所有模块的可编辑字段与操作见 [参数位置与编辑说明](effects-parameters.md)。

验证：真实 Blender 覆盖度数/原生弧度、独立组件/Transform、增删预览、拒绝重复身份、删除失败保留、撤销/重做、保存重开，以及删光后从来源重新添加。原生构建覆盖新增和删除结合自定义 Mesh/材质/图片、LOD 登记、运行清单粒子计数、确定性重建和无效拓扑拒绝后保留产物。当前用户工程也完成隔离构建；产物在 `bin/effect-emitters-20261020`，没有安装到游戏或保存用户工程。

## 自定义 Mesh、材质与贴图（2026-10-20）

1. 在 **特效结构 → Mesh · Plane001** 直接选择来源网格，或选发射器 → **渲染：面片 / Mesh / 材质 → 编辑粒子 Mesh**。正常编辑顶点、UV、法线和静态修改器即可。旧工程在特效结构中点击一次 **展开引用的 Mesh 与材质**，保留已有自定义网格与材质设置。也可在 **自定义粒子 Mesh** 指定另外的网格对象。
   要合并自己的模型：先选自己的模型，最后 Shift 选导入的粒子网格，让它成为活动对象，再 Ctrl+J；在编辑模式删除不需要的原花瓣几何。合并后选全部面，指定到需要的 EFF 材质槽。不要将多个不同材质的面直接混合导出。
2. 使用该对象的局部几何和当前修改器结果；对象旋转/缩放烘焙到粒子形状，对象位置不移动发射范围。粒子大小继续由出生大小控制。资源对象不是另一份游戏模型，不要为它单独导出人物 Part。当前每个自定义网格只支持一个面材质，必须有 UV；不输出逐粒子的蒙皮或形态键动画。来源必须具有可用的 Mesh 结构模板；推荐粉花瓣/梨花瓣来源已经具备。
3. 网格已挂上实际对应的 EFF 材质，选网格 → **材质属性 → EFF 材质**。特效和普通模型实际使用同一个材质编辑器、Material 数据块上的 `eiem_*` 作者属性与原生字段写入器。搜索、功能开关、颜色、数值、UV 变换和文件夹选图操作均复用原实现。渲染块的 **编辑材质 / 贴图** 跳到材质 Empty 时也显示同一套控件，编辑同一个 Material。构建使用面上指定的当前特效 EFF 材质，不把 Blender 普通节点 Shader 自动转换为游戏 Shader。节点材质仅作近似预览。
4. 贴图框默认保留游戏来源路径，点文件夹选 PNG/TGA 等本地文件；选择时只保存路径，预览/构建时再读取。清空作者路径恢复来源；空槽通过 **添加空贴图槽** 选择来源已经声明的槽。UV 缩放/偏移在 **贴图变换** 中。采样设置沿用对应来源 Texture2D。旧工程已选的图片、打包/绘制像素保留为兼容替换，选择新文件后使用共用路径。
5. 粉花瓣真实 Shader 为 `HGRP/Effect/VFXDitherAlpha`：共用功能视图显示主图与颜色、第二主图、透明遮罩、UV 扰动、法线、溶解与菲涅耳，开关同步该 Shader 的数值与关键字。**原始参数** 可查看完整来源字段，float/int/颜色/向量使用对应控件。两套发射器共用 `M_fxmap_common_camphor_leaves_04` 与 `Plane001`；修改共用材质同时影响二者。`_MainTex`、`_MaskTex` 等槽必须分别检查：仅换主图时原遮罩仍然保留。人物材质和特效材质的功能组随真实 Shader 改变，编辑方式一致。
6. 特效的颜色/透明度模块会提供粒子颜色与 Alpha，序列帧模块提供 UV；显示结果还取决于来源 Shader 是否读取这些数据。材质页设置基础参数，任意材质数值随粒子寿命变化的自定义轨道目前未提供，不等于所有材质参数都能被粒子模块驱动。
7. 修改后选要导出的特效根或发射器，使用 **文件 → 导出 → EFF Mod 包**；可一次选多个特效。之后使用同一菜单的 **EFF 快速更新所选 Mod**，更新上次目录。人物与特效一起选中则一起导出。游戏默认 F9 重载特效。新 Mesh、材质和图片都在隔离 Bundle 里，沿用普通 eff.dll。

渲染块的 **运动矢量** 可选“仅相机运动 / 物体运动 / 强制无运动”。移动粒子使用 TAA/TAAU 时，此设置关系到时间重投影；“物体运动”仍取决于游戏是否为该粒子路径提供正确的历史位置，不能保证仅切换此项就消除拖尾。它不修改 Mesh 的 UV，也不等于开启 TrailModule。

纯特效更新会在完整内容校验后跳过无变化的编译，完成提示会列出整理、构建、发布耗时。当前花瓣追加到角色包实测：参数变更约 2.26 秒、未改约 0.88 秒；14 网格首次全量仍约 14.14 秒。导出前仅选择特效根或子发射器可走特效更新，选入角色网格则进入角色与特效一起导出的路径。

更新插件后可使用新增界面。构建器必须选择支持资源新增的配套 AnimeStudio；本地开发路径为 `tools/AnimeStudio/AnimeStudio.GUI/bin/Debug/net9.0-windows/AnimeStudio.GUI.exe`，旧 dist 版本尚不能构建自定义资源。旧工程重新打开时迁移材质参数并补齐共用控件，保留原有修改。

## 预览

### 原生色带编辑颜色与透明度（2026-10-21）

**出生颜色、颜色与淡入淡出、颜色随速度、拖尾颜色和自定义颜色**中的渐变使用 Blender 原生 ColorRamp 控件，直接显示在原来的特效模块内，无需创建材质节点或另外打开编辑窗口。常量颜色仍使用选色器；模式选 **渐变 / 随机双渐变 / 渐变随机取色** 时显示对应色带，随机双渐变同时显示 A、B 两组。

- **颜色**：拖动下方的三角标记调整位置，选中标记后点色块选颜色。
- **透明度 Alpha**：独立色带；选中标记后点色块，在颜色弹窗中修改 **Alpha / A**，0 为透明、1 为不透明。此条只读取 Alpha，RGB 由上面的颜色色带控制。
- 色带自带 **＋ / －** 用于添加、删除选中的标记；位置也可精确输入。颜色和透明度的位置独立，分别最多 8 个标记，与游戏格式一致。
- 插值使用 **Linear（线性）/ Constant（固定）**，两条色带自动同步插值。其他 Blender 插值或 HSV 模式没有对应的原生字段，会显示错误并阻止导出；可修正设置或点击 **恢复当前参数的色带**。
- 默认折叠 **精确数值 / 原生渐变点**，仅需检查原始数据时再展开。色带改动自动同步预览；立即导出、保存也会同步，无需手动应用。关闭模块不会删除渐变，修改色带不会自动启用模块。

色带只是原生 Gradient 数据的编辑投影，导出仍写入独立 RGB/Alpha 关键点、UInt16 位置和原生插值模式。打开界面不会重采样或改变来源数据；Blender 保存与撤销/重做保留编辑。当前用户花瓣的颜色模块按要求保持关闭。

验证覆盖实际 ColorRamp 拖动/增删、RGB/Alpha 独立、双渐变、容量与插值拒绝、原始字段反向同步、撤销/重做、立即保存/导出和重开。原生编译结果重新解码与作者粒子字段一致；模块导航及原有数值 F-Curve 回归通过。测试产物位于 `bin/effect-gradients-20261021`，没有改变游戏发布包或保存用户工程。

新导入默认使用 **发射数量** 模块，不执行原 Prefab 的自动数量覆盖。旧工程若提示高级自动规则已启用，点 **使用下方的发射数量**；**设为持续发射** 同样关闭覆盖。确需按挂点缩放计算数量时，展开 **高级：按缩放自动计算数量**，主动启用后编辑发射数/缩放/轴遮罩。这是原特效自带的可选组件，不要求编写脚本。

根开启离线预览/显示发射范围，播放或拖动时间线。直接修改字段每 0.1 秒检测变化，也可手动刷新；实际刷新延迟还包括预览计算时间。预览几何是派生显示，不写入来源拓扑。

支持普通 billboard、来源 Mesh、发射率/爆发、寿命/速度/重力、大小/颜色/透明度曲线、旋转、部分速度曲线、网格图集动画和世界/局部跟随。图集预览按全图/单行、起始帧、生命周期曲线或 FPS 更新 UV；按粒子速度播放目前暂按寿命进度近似，并在特效根报告。Sprite 列表动画、Mesh Index 选行和特殊 billboard 尚未还原。世界粒子按出生时发射器变换采样；球/半球/锥/盒/圆/线/矩形/圆环提供范围线框，应用来源 TRS。

## 构建和挂载

1. 导入真实角色 .eff，特效根的 **挂载与显隐** 选择目标 Mesh 和骨骼。Mesh 证明 Renderer/完整骨架归属；可选未被该 Mesh 蒙皮使用的骨骼。**骨骼必填**，根 TRS 调整偏移。默认随 Mesh 出现/隐藏，事件触发暂不支持。
2. **统一导出入口：文件 → 导出 → EFF Mod 包**。仅选一个或多个特效根/发射器，导出只含这些完整特效及依赖的包；挂载目标 Mesh 不会因为被引用就一起导出。选同一特效的根和多个子节点会自动去重，选发射器表示选择所属完整特效；若只保留一个发射器，应先用“删除发射器”移除另一个。人物 Mesh 和特效一起选中则使用全部资源一起导出。粒子资源 Mesh 属于特效，不会作为人物部件重复导出。
3. 在统一导出窗口填 **Mod 文件夹名**，文件浏览器选父目录（例如 `游戏/plugin/mods`）。新建特效专用包为 `[Mod] type=effect`，不要求人物 Mod 或 compiled.bin。**也可直接更新已有角色包**：只选特效，父目录选 `mods`、名字填 `lx`，写入 `mods/lx/mod.ini`；按特效 ID 追加或更新，保留角色网格、材质、贴图、控制、其他未选特效、玩家状态和嵌套子包。挂载 Mesh 已在角色包里时自动关联对应 Part，继续跟随网格显隐与切换。角色包需已完整导出过；人物完整导出仍不能覆盖独立特效包。导出前摘要显示网格与特效数量。

   支持嵌套独立 Mod，例如角色包为 `mods/lx/mod.ini`，花瓣包为 `mods/lx/petals/mod.ini`。只选花瓣时，浏览器选父目录 `mods/lx`，Mod 文件夹名填 `petals`。DLL 启动、F10 与 F9 都递归发现包；父包校验与导出忽略子包资源，重新导出 `lx` 保留 `petals`。每包使用自己的 `mod.ini`、资源和挂载设置，Mod id 仍需全局唯一；点号开头的临时/备份目录不参与扫描。子文件夹仅用于组织，挂载关系仍由特效设置决定。
4. 后续仍选要导出的资源，使用 **文件 → 导出 → EFF 快速更新所选 Mod**，或 N 面板 **EFF → 网格切换 → 快速更新所选 Mod**，无需再选文件夹。上次目录由场景统一记录，特效物体不再承担导出目录和导出操作。**只选特效更新角色包时，未选特效保留**；独立特效包或人物全部资源导出仍由本次导出范围决定完整内容。人物 Mesh 的“随 Mod 导出”关联特效仍自动带出；显式选中的特效即使关闭此开关也会导出。
5. 游戏使用普通 plugin/eff.dll。导出后按 **F9** 从磁盘更新特效；支持增删、改挂点/偏移。准备/挂载失败保留旧成功实例。
6. plugin/eff.ini 的 [Hotkeys] effects_reload=F9 可改键，改后 F10 重读配置。全局/Mod 按键冲突会拒绝。Blender 不承担 PID、实例管理或游戏重载，无需额外特效 DLL。

编译器在根的 **构建工具 → 编译器 / 编辑数据** 中设置，必须支持 `--build-eff-effects`。该折叠区保留手动构建及 `.effedit.json` 编辑数据导出；日常 Mod 导出使用统一入口，自动构建当前参数、网格、材质和贴图。未改变的原生资源复用已校验的构建，仅改挂载骨骼或根偏移也不重建 Bundle。批量构建全部成功且参数仍为当前值后才发布；失败、取消或构建中再次改参保留上一份已发布 Mod。自动缓存位于 Blender 用户数据目录 `eiem/effect-builds`，校验作者内容、真实来源、编译器及 Bundle。

2026-10-20 当前花瓣场景的隔离测试：改参数约 0.92 秒，改粒子 Mesh 约 0.93 秒，未改资源或只改根偏移约 0.28～0.29 秒；包含导出，不包含游戏 F9 加载。测试覆盖失败保留、损坏缓存重建、同大小/时间戳来源损坏拒绝、完整导出使用最新特效和玩家 state.ini 保留。完整人物导出的热点及实测见项目 `docs/blender-export-performance-20261020.md`。

package-protocol.json 是 DLL 的**数据结构能力清单**，不是特效或用户配置。导出器核对 effectAttachment、effectTarget、standaloneEffect 等结构；随 DLL 配套替换，不可手改能力冒充兼容。
