# EFF actions

An EFF action owns one Clip ID, time range, sample rate, playback speed, loop/autoplay state, and toggle key. Shape Keys, bones, author Empty transforms and material parameters are channels of that action. A native Blender Action may contain KEY, OBJECT and MATERIAL slots together; they export as one EFF Animation. Existing groups that reference several source Actions remain editable without moving or deleting their keyframes.

1. Insert keyframes on Shape Key values, Pose Bone or author Empty transforms, or the existing EFF material editor values. Use Blender's Action Editor and Graph Editor to edit the source Actions and their slots.
2. Open N → EFF → **EFF 动画**. The action list displays the configured EFF actions and unregistered Blender Actions. Click **加入** next to an existing Action to bind its supported slots together, or select animated objects and click **从所选创建动作**.
3. Set the name, export switch, start/end frames, toggle key, loop, autoplay, speed and sample rate once on the action. The initial range is the union of its source keyframes; later imports retain the chosen range.
4. All supported channels in each bound Action slot are listed automatically, with their target and source Action. Add or delete curves in Blender's Action/Graph Editor; the EFF list and export immediately follow those edits. There is no second channel whitelist to maintain. **添加所选对象** binds additional animated owners to the action. The action's **导出** switch controls the complete animation.
5. Export Meshes to export their animation channels and actual dependencies: used material slots, bound rigs, and explicitly selected effect mounts. Other owners of the same Action need not be selected; unused or removed materials do not block export or add channels. Playback and control stay on the shared EFF Animation, and its export switch still controls the included contributions. Material animation has no separate Properties panel, parameter picker, playback clock or type-specific import button. Use Blender's normal timeline to inspect source keyframes.

Format 3 declares one `[Animation...]` and one sample resource for the action, with all its Shape, Bone and Material targets. Shape targets use control variables, Bone targets use Skeleton IDs and hierarchy paths, and Material targets name shader properties. INI remains the assembly and key-control entry point.

Material contributions retain their own source Action and MATERIAL slot, just like the KEY and OBJECT contributions. Switching or clearing the editor's active Action cannot redirect registered channels. Old records migrate only when the source is unique; an ambiguous legacy record offers a source Action picker rather than choosing another Action silently. Imported mixed animations keep their shared group ID, playback settings and original INI variable names on re-export.

Real Blender regression coverage includes a native Action with all three slot types, one F6-controlled exported clip, synchronized samples, atomic mixed-channel import, channel removal/reimport and the unified panel. Earlier game probes cover native mixed AnimationClip evaluation; those do not replace game verification of an author's exported Mod. Drivers and unbaked NLA must be baked to independent Actions first.
