# 形态键动画

配套 EFF v1.6.0、Blender v0.43.0。Windows x64 / Blender 5.0，已在 Blender 5.0.1 验证作者流程。

1. 选中带 EFF 来源绑定的 Mesh，在形态键的 value 上插入关键帧。Action 属于 Shape Keys 数据块；Object 的位置、旋转 Action 不能用于此处。
2. 打开 N → EFF → 形态动画组管理，统一列表显示工程内所有播放组、成员数和按键，无需选中网格也能查看和编辑。选中要同步播放的网格后，点击“从选中网格动画创建播放组”。每个网格必须有来源绑定与 Shape Keys Action；各自读取有效 KEY slot，创建时使用所有成员的关键帧范围并集。
3. 点击组名后，“本组网格与形态频道”逐个展开成员，直接在同一面板编辑各自 Action/slot/频道，无需切换活动网格。可“加入选中网格”、点击铅笔选择成员物体，或点击 X 将其移出。加入成员保留组的播放范围，需要扩展时点击“使用动作范围”。名称、导出开关、范围、循环、自动播放、按键、倍率与采样率全组共享。“更多设置”提供作者默认倍率和采样率，默认 60Hz。
4. 预览同时播放全组成员勾选的频道；停止后恢复所有成员原 Action、slot、当前帧、范围和权重。
5. 点击“选中全部成员”，使用“全部资源”或“仅 Mesh”导出。未选齐会在采样前提示缺少哪些网格；仅材质/贴图导出保留动画。移出成员后，更新已发布的组时仍须把原成员和保留成员一起选中导出，以清理原频道绑定。
6. 游戏内快捷键播放/停止，Ins 的“形态动画”区支持播放、暂停、停止、倍率滑块和直接输入。倍率立即生效、保持当前进度并保存为玩家偏好。

网格形态键可以正常删除。刷新形态键控制或导出时，插件会清理已删除形态键的控制记录（含手动控制及复制网格遗留的记录），保留仍存在形态键的设置。删除已发布的形态键后请使用“全部资源”导出；“仅 Mesh”更新仍要求保留已有控制绑定。如果动画组仍使用已删除的频道，请先在组内取消该频道，或将不再参与动画的网格移出组。

停止或非循环动作播放完毕后恢复手动权重；操作形态滑块或原形态快捷键会先停止关联动画。F10 重建播放状态：初始自动播放的组从头开始，其余停止，合法的玩家倍率继续保留。同一 Mod 的多实例共享播放时间。

同一个网格、同一个形态频道可以用于多个组。不同频道的组能同时播放；启动某组时，会停止正在控制重叠频道的整组（包括暂停组），再从头播放新组，避免同一权重被两个动作覆盖。停止已被替换的旧组不会影响新组。面板提示共享频道的其他组。多个冲突组同时自动播放时，按稳定组身份顺序启动，最终只保留最后启动的组；建议只为其中一个开启自动播放。不支持动作混合、渐变或停止保持姿态；驱动器与 NLA 仍需先烘焙。

片段独立保存为 resources/shape_animation_<ID>.bin，引用已有 Mesh 形态数据，不重复嵌入几何。游戏每帧推进时间、插值频道并写入原生权重，不重建 Mesh/PFB，也不逐帧保存动画权重或刷新完整面板。

多网格组导出为一个片段、共用一个播放时间和一个速度变量，Ins 只显示一项。不同网格不必使用相同形态键名称，可以使用同一个 Action 的不同 KEY slot，或各自独立 Action。复制带播放组的 Mesh 数据会保留该组身份；关联复制的多个 Object 共用同一个 Mesh 成员。共享频道需要新版配套 DLL／编译器声明 `shapeAnimationPlayback=shared-channel-groups/replace-conflicting-playback`，更新前导出会保留上一 Mod 并明确报错；原动画资源字节结构不变。

Blender Action/slot、频道采样与预览恢复，Python/C++ 包往返、播放/暂停/循环/调速/手动交接及真实资源隔离编译已有回归。新动画的游戏内显示和活跃动画性能仍需实机验收。
