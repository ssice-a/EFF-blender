# 形态键动画

配套 EFF v1.5.0、Blender v0.42.0。Windows x64 / Blender 5.0，已在 Blender 5.0.1 验证作者流程。

1. 选中带 EFF 来源绑定的 Mesh，在形态键的 value 上插入关键帧。Action 属于 Shape Keys 数据块；Object 的位置、旋转 Action 不能用于此处。
2. 打开 N → EFF → 形态动画，点击“从当前动画创建播放组”。它读取当前 Shape Keys Action、KEY slot 和关键帧范围。
3. 勾选参与频道，设置范围、循环、初始自动播放与游戏快捷键。手动换 Action 后选择其 KEY slot 并点击“读取动作频道”。“更多设置”提供作者默认倍率和采样率，默认 60Hz。
4. 预览只播放选中的频道；停止后恢复原 Action、slot、当前帧、范围和权重。
5. 使用“全部资源”或“仅 Mesh”导出动画。仅材质/贴图导出保留动画。一个组跨多个部件时，部分导出必须选齐这些部件。
6. 游戏内快捷键播放/停止，Ins 的“形态动画”区支持播放、暂停、停止、倍率滑块和直接输入。倍率立即生效、保持当前进度并保存为玩家偏好。

停止或非循环动作播放完毕后恢复手动权重；操作形态滑块或原形态快捷键会先停止关联动画。F10 重建播放状态：初始自动播放的组从头开始，其余停止，合法的玩家倍率继续保留。同一 Mod 的多实例共享播放时间。

第一版每个频道只能属于一个启用的播放组，不支持一键轮换多个 Action、渐变或停止保持姿态。驱动器与 NLA 必须先烘焙为独立 Shape Keys Action。只接管已声明频道，不增加骨骼动画或自定义骨架控制；原有静态 Renderer 和多帧形态限制继续适用。

片段独立保存为 resources/shape_animation_<ID>.bin，引用已有 Mesh 形态数据，不重复嵌入几何。游戏每帧推进时间、插值频道并写入原生权重，不重建 Mesh/PFB，也不逐帧保存动画权重或刷新完整面板。

Blender Action/slot、频道采样与预览恢复，Python/C++ 包往返、播放/暂停/循环/调速/手动交接及真实资源隔离编译已有回归。新动画的游戏内显示和活跃动画性能仍需实机验收。
