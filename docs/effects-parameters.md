# 特效参数位置与编辑说明

入口：选发射器 Empty → **数据属性（坐标轴图标）→ EFF 特效 · 发射器**。选根会显示全部发射器；选子发射器只显示它的参数。模块左侧三角展开/收起，勾选框启停，关闭保留设置；**启用模块…** 可以重新开启来源已有的模块。

这里列出当前界面的字段及修改方法。参数以来源 Unity TypeTree 为准；某来源没有的字段不会凭空添加，未确认语义的字段保留原名/unknown。每个模块末尾的 **高级 / 其余原生字段** 保留其余可写字段，悬停可看原生路径和类型。

## 数值、随机、曲线和渐变怎么改

常用操作：选发射器 → 顶部 **编辑全部曲线**。同一发射器共用一个 Blender 曲线窗口，首次打开会收集已启用的数值曲线。右侧 **EFF 曲线** 页签点 **添加属性…**，搜索“大小”“速度”“旋转”等并选中，即可加入；所属模块会启用，常量/随机范围按原数值转换为平直曲线。已有曲线保留原形状。

左侧按模块分组：点一条曲线编辑它，Shift 多选可一起编辑；右侧 **只看选中曲线** 暂时隐藏其他曲线，**显示全部** 恢复。选点后 G Y 改值、G X 改进度；默认键位下 Ctrl+右键在鼠标位置加点，选点按 X 删除，Ctrl+Z 撤销。编辑自动同步，关闭窗口保留修改。右侧栏不见时按 N，再选择 **EFF 曲线** 页签。

**移出列表** 只整理当前编辑列表，游戏里的参数仍然生效；**改为常量…** 才会停用这个属性的曲线变化，并使用输入值。列表会随 `.blend` 保存。**加入已有曲线** 可将已启用的来源曲线重新收集进来。只能添加来源格式支持的数值属性，颜色/Alpha 继续用渐变控件编辑。

| 控件 | 操作与含义 |
| --- | --- |
| 常量 | 直接点击数值输入；拖动也可调整。float 为浮点，int 为整数，bool 为勾选 |
| 随机范围 | 在参数右侧模式选“随机范围”，填最小/最大；出生时随机旋转也用此模式 |
| 曲线 | 点顶部 **编辑全部曲线**；参数旁 **在统一曲线窗口中编辑** 将该参数及适用分轴加入同一个窗口。原生数值表折叠在 **精确数值 / 原生关键点与切线** |
| 随机双曲线 | 右侧属性的“类型”改为“随机双曲线”，显示 A/B 两端，使用共同倍率，允许交叉。速度、大小、旋转等属性可跨模块共同编辑；X/Y/Z 表示对应参数的三轴分量 |
| 曲线横轴 | 发射率曲线按系统周期进度；生命周期变化曲线按每片已过寿命。图中 0% 为开始、100% 为结束；原生数值表仍为 0..1 |
| 颜色 / 随机双色 | 点击颜色框编辑 RGBA，模式切换随机双色后显示两端颜色 |
| 渐变 / 随机双渐变 | 调整颜色点数、透明度点数，再直接改位置和颜色/Alpha；位置 0..1。增加点数添加条目，减少点数停用末尾条目，原生最多各 8 点 |
| Alpha | 0 透明、1 不透明；颜色点和透明度点的位置分别控制。Shader 必须读取粒子 Alpha 才能在游戏里淡出 |
| 旋转 | 出生旋转输入 °；旋转随寿命/速度的角速度输入 °/s。图形纵轴已换算为角度/角速度；高级原生关键帧表仍是倍率，原生存储仍为弧度 |
| 资源引用 | 旁边选择按钮切换已经解出的兼容来源资源；自定义网格使用渲染块的“自定义粒子 Mesh” |
| 列表 | “添加…”增加一条，复制按钮复制该条，X 删除该条。爆发条目数量自动同步，曲线按时间排序 |

这是 Blender 自带的 Graph Editor，可拖动系统窗口边缘改变大小。滚轮缩放，中键平移，Home 显示全部；选中点后 G X 调时间、G Y 调数值，N 侧栏可精确输入关键点和手柄坐标。V 菜单选择自由、对齐、矢量或自动手柄；T 菜单支持贝塞尔和线性插值。新增关键点可用顶部 **关键帧（Key）→ 插入关键帧 → 在游标位置插入所选通道**：先在 N 侧栏设置二维游标位置、选择目标通道，再插入；X 删除选中的点。按键随 Blender 的键位设置生效。

纵轴显示 **共同倍率 × 原生曲线值**，所以速度可直接按单位/s编辑，大小是倍率。共同倍率为 0 时显示归一化值，并提示实际输出为 0；要出现效果仍需回参数页调整倍率。编辑自动同步，关闭窗口保留修改；Esc 取消当前 Blender 移动操作，Ctrl+Z / Ctrl+Shift+Z 使用 Blender 原生撤销/重做。保存和导出会主动同步，拖动按间隔更新当前发射器的离线预览。

不同属性的纵轴单位不同，右侧每项标明单位及横轴含义。发射数等曲线与速度/大小数值相差过大时，先用“只看选中曲线”聚焦；也可使用 Blender 顶栏 Normalize 进行归一化比较，开启后图中坐标就不是实际数值。横轴统一画成 0–100，但系统周期、粒子寿命和速度范围是各自的进度，不是同一条绝对时间轴。

F-Curve 修改器、恒定/缓动等其他插值不能直接写入来源格式，使用时会明确报错并阻止导出。修正对应设置，或点右侧报错下的 **丢弃未同步修改 / 重新载入**。窗口通过临时隐藏对象及独立 Action 映射原生曲线，关闭后自动清理；发射器已有动画不受影响。原生加权切线同时用于预览采样与积分；图形可编辑不代表所有模块都已支持离线模拟，仍以各模块提示为准。颜色渐变保留颜色/Alpha 控件。

## 发射器基础

| 参数 | 改什么 |
| --- | --- |
| 系统周期 (s) | 发射器一次播放多久；是发射时间范围，不是每片粒子的寿命 |
| 循环播放 | 勾选后每轮结束继续，持续发射必须检查此项 |
| 预热一轮 | 循环系统开始时预先模拟一轮；影响刚显示时是否已有粒子 |
| 开始延迟 (s) | 挂载/启用后延迟多久开始 |
| 播放速度 | 整个粒子模拟的速度倍率 |
| 模拟空间 | “局部”让已发射粒子跟随挂点；“世界”让已发射粒子留在世界；自定义空间另选 Transform |
| 缩放方式 | 选择整个层级、当前节点或仅发射形状受缩放影响 |
| 启用时播放 | 对象被启用时开始播放 |
| 自动随机种子 / 随机种子 | 关闭自动后可输入固定种子；离线预览的确定性采样不等同 Unity 随机序列 |
| 出生寿命 (s) | 每片粒子存活多久；支持常量/随机范围/曲线 |
| 初速度 (单位/s) | 出生时沿发射形状给出的方向运动，正负值改变方向 |
| 出生大小 | 初始大小；勾选“分别设置 XYZ 大小”后分别修改三轴 |
| 出生旋转 X/Y/Z (°) | 出生朝向；勾选“分别设置 XYZ 旋转”后显示三轴，模式选随机范围可分别随机 |
| 出生颜色 | 粒子初始颜色/透明度，与后续颜色模块及材质相乘，具体取决于 Shader |
| 重力倍率 | 对场景重力的倍率 |
| 最大同时存活数 | 本发射器容量上限；不是每秒数量 |
| 高级字段 | 反向旋转概率、屏外模拟、停止后行为、时间缩放、挂点速度来源等，以当前来源字段为准 |

## 发射数量

| 参数 | 编辑方式与作用 |
| --- | --- |
| 每秒发射数 | 常量表示匀速生成；曲线按系统周期变化；随机范围/双曲线改变速率的随机性 |
| 每单位移动发射数 | 挂点每移动一个单位发多少片；零为关闭按距离生成 |
| 定时爆发 → 时间 (s) | 当前系统周期内何时一次生成一批 |
| 爆发 → 发射数量 | 该批数量，支持常量/随机范围等原生模式 |
| 爆发 → 重复次数 | 该条爆发重复几次；当前界面注明 0 为无限重复 |
| 爆发 → 间隔 (s) | 同一条爆发的重复间隔 |
| 爆发 → 触发概率 | 每次爆发的发生概率 |
| 设为持续发射… | 输入每秒数量与容量后，开启循环、使用常量速率、清空全部爆发并关闭按距离生成；会在对话框里写明修改范围 |

每秒发射与爆发是叠加关系。需要取消成批出现，删除对应爆发；需要速率恒定，将每秒数量的模式改为常量。粉花瓣有两个发射器，要分别检查。

## 发射形状与范围

| 参数 | 改什么 |
| --- | --- |
| 类型 | 球/球壳、半球、锥、盒体/盒壳/盒边、圆盘/圆边、线段、圆环、矩形、Mesh/Sprite 等原生形状 |
| 半径、半径厚度比例 | 球、锥、圆等的范围与壳层厚度；仅在适用类型显示 |
| 锥角 (°)、长度 | 锥的张角和长度 |
| 圆弧 (°) | 圆盘/圆边/圆环的覆盖角度 |
| 圆环管半径 | 圆环截面粗细 |
| 盒壳厚度 | 盒壳/盒边的厚度分量 |
| 形状位置 / 形状旋转 (°) / 形状尺寸 | 修改出生区域在发射器局部的偏移、方向、XYZ 范围 |
| 朝向发射方向 | 将粒子初始朝向对齐发射方向 |
| 随机方向比例 / 球面方向比例 / 随机位置量 | 修改出生方向与位置的随机偏离 |
| Mesh 引用、法线偏移、采用 Mesh 颜色 | Mesh 形状的采样来源和沿表面法线偏移；这是**出生区域网格**，每片花瓣使用的网格在渲染块 |
| 高级 Mesh/贴图采样字段 | 采样顶点/边/面、材质槽限制、贴图裁剪/通道/阈值等，按来源字段展开 |

移动/旋转整个发射器 Empty 会移动/旋转它的发射原点。根 Empty 的 TRS 是挂载偏移。根的 **显示发射范围** 展示已支持形状的线框；Mesh/Sprite 采样形状尚未离线还原。

## 运动

| 模块 | 可改字段与作用 |
| --- | --- |
| 速度随生命周期 | X/Y/Z 速度、世界坐标、绕 XYZ 轴轨道速度、轨道中心偏移、径向速度、速度倍率；叠加在初速度上 |
| 继承发射器速度 | 出生时/持续继承模式及倍率曲线；控制挂点移动对粒子的影响 |
| 寿命随发射器速度 | 速度范围、寿命倍率曲线；根据挂点速度改变出生寿命 |
| 力随生命周期 | XYZ 力、坐标空间、每帧重新随机；持续改变速度 |
| 外部力场 | 倍率曲线、力场过滤方式/层遮罩/引用列表 |
| 速度限制与阻力 | 统一/分 XYZ 上限、坐标空间、超速阻尼、阻力，以及阻力是否乘粒子大小/速度 |
| 噪声扰动 | XYZ 强度、频率、阻尼、叠加层数/强度/频率倍率、质量、滚动速度、位置/旋转/大小影响量及重新映射曲线 |

继承速度、按挂点速度改寿命、力、外部力场和限速阻力可以原生编辑，但离线预览暂未实现。噪声仅做近似位置摆动，不等同游戏噪声。

## 外观随生命周期 / 速度变化

| 模块 | 怎么改 |
| --- | --- |
| 颜色与淡入淡出 | 启用后改“颜色 / Alpha”的模式；渐变的透明度点控制淡入淡出，末端位置表示接近死亡时的 Alpha |
| 大小随生命周期 | 改大小倍率曲线；启用分别控制 XYZ 后分轴编辑，乘以出生大小 |
| 旋转随生命周期 | 改角速度常量/范围/曲线；单位 °/s。分别控制 XYZ 后可让花瓣绕多轴旋转 |
| 颜色随速度 | 速度范围映射到颜色/Alpha 渐变 |
| 大小随速度 | 速度范围映射到统一/XYZ 大小倍率 |
| 旋转随速度 | 速度范围映射到统一/XYZ 角速度，单位 °/s |
| 贴图序列帧 | 网格图集/Sprite 模式；图集列数/行数、全图/单行、生命周期/速度/FPS 推进、起始帧、循环次数、选行方式/行号、UV 通道遮罩、U/V 翻转比例 |

按速度改变颜色/大小/旋转可以原生编辑，离线预览暂未实现。网格图集的生命周期和 FPS 模式可预览起始帧及全图/单行 UV；按粒子速度播放暂按生命周期近似，Sprite 列表、Mesh Index 选行和复杂 UV 尚未完整还原。

## 渲染：面片 / Mesh / 材质

| 参数 / 入口 | 怎么改 |
| --- | --- |
| 渲染方式 | Billboard、速度拉伸/水平/垂直面片、Mesh 或不渲染 |
| 来源 Mesh / Mesh 2..4 | 选择已经解出的来源网格引用 |
| 自定义粒子 Mesh | 指定自己的 Blender 网格；“编辑粒子 Mesh”选中实际资源网格，然后正常 Tab 编辑顶点和 UV |
| 材质 / 使用材质 | 显示渲染器实际引用；自定义网格按实际面使用的 EFF 材质槽导出，目前一个面材质 |
| 编辑材质 / 贴图 | 打开同一份普通 EFF 材质编辑器；也可选网格 → 材质属性 → EFF 材质。贴图用原有文件夹按钮替换路径，颜色/数值/UV 在相应功能组或原始参数里改 |
| 朝向空间、中心偏移、随机翻转 | 面片或 Mesh 的朝向基准、枢轴与翻转 |
| 相机速度拉伸、粒子速度拉伸、长度倍率 | 速度拉伸面片使用 |
| 排序方式/偏移/顺序、屏幕最小/最大大小 | 透明粒子排序及屏幕尺寸限制 |
| 高级 | 顶点流、GPU 实例化等来源渲染器字段，必须与 Shader 匹配 |

新增发射器初始共享 Mesh 和材质，所以修改同一网格/材质会影响所有引用者；发射数量、寿命、形状等模块参数独立。材质修改基础外观；粒子颜色/Alpha/UV 由相应模块提供，能否作用到画面取决于来源 Shader。任意材质数值随寿命变化的自定义轨道当前未提供。

## 交互、扩展与游戏整体控制

| 模块 | 可编辑数据 |
| --- | --- |
| 粒子碰撞 | 平面/世界、3D/2D、碰撞平面/层、阻尼/反弹/寿命损失、消亡速度阈值、碰撞半径、质量/体素、动态碰撞体和受力/回调等 |
| 粒子触发器 | 内部/外部/进入/离开时忽略、消亡或回调，碰撞体列表/查询 |
| 子发射器 | 关联已有粒子系统、出生/碰撞/死亡等事件、继承选项、发射概率；这是模块内的**事件关联**，额外新增完整发射器使用顶部按钮 |
| 粒子灯光 | 灯光来源、比例/随机分配、粒子颜色、范围/强度曲线及上限 |
| 粒子拖尾 | 单粒子/带状、比例、寿命、最小顶点间隔、铺设方式、宽度/颜色、世界空间/随粒子消亡等 |
| 着色器自定义数据 | 两组流的关闭/向量/颜色模式，向量分量数和 XYZW 曲线或颜色渐变；需匹配渲染器顶点流与游戏 Shader |
| 游戏整体控制 | 来源 EffectSetting 的整体循环、持续时间、延迟、淡入淡出等已有字段；这是整个特效的脚本配置，不是单片寿命 |
| 其他脚本组件 | 按真实来源字段编辑；例如粉花瓣有 VFXAutoEmissiveRate。不能仅凭字段名字保证它在游戏里的完整行为 |

上述交互/脚本不由离线预览执行，部分字段还需要同场景引用对象和游戏脚本配合；能够编辑不代表任意组合都能在离线预览或游戏中运行。特效挂载后的自定义事件触发目前未支持，默认随挂载 Mesh 显隐。

## 增删发射器

选根或发射器 → 顶部 **添加发射器…** → 选已有模板、填新名称。新增的完整原生组件与参数独立，初始 Mesh/材质共用。选子发射器 → **删除发射器**；若存在子节点先处理子节点，根不能在这里删。删光后仍可从“来源模板”重新添加。Ctrl+Z / Ctrl+Shift+Z 撤销和重做。普通 Shift+D/X 不是原生发射器增删入口。

修改后仍走 **构建特效资源 → 导出独立特效 Mod** 或随人物导出；普通 eff.dll 可加载，游戏默认 F9 更新。界面/原生构建已离线验证，最终画面仍需实机确认。完整资源编辑与导出说明见 [特效编辑](effects-editor.md)。
